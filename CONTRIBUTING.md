# Contributing to Kata

Thanks for helping. Two things to know before you open a pull request.

## 1. Sign off every commit (Developer Certificate of Origin)

We use the [Developer Certificate of Origin 1.1](https://developercertificate.org/).
By adding a `Signed-off-by` line you certify that you wrote the change, or
otherwise have the right to submit it, under the terms below.

```bash
git commit -s
```

Every commit in a pull request must carry the line:

```
Signed-off-by: Your Name <you@example.com>
```

## 3. Practical bits

- Open an issue or discussion first for anything larger than a bug fix.
- Keep pull requests focused. One change per PR.
- Match the existing style of the area you touch; there is no global linter yet.
